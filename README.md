# Proyect K

Base para un juego de peleas 2D diseñado primero para móvil.

## Tecnología

- Phaser 3 para el motor 2D.
- TypeScript para el código del juego.
- Vite para ejecutar y compilar el proyecto web.

## Próximos elementos del juego

- Personajes y animaciones.
- Escenarios.
- Controles táctiles: movimiento, salto, ataque y bloqueo.
- Sistema de combate, salud y rondas.

## Arranque local

Cuando estén instaladas las herramientas de desarrollo, ejecuta:

```bash
npm install
npm run dev
```
